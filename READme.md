# T-GPT — Пет-проект разработчика Зюзичева Ивана с идеей, как бы выглядела нейросеть если бы Т-Банк выпустил на рынок. Чтобы нейросеть действительно отвечала на сообщения осознано было выбрано ядро на базе GigaChat API.

> **Дисклеймер**: Этот проект **не имеет отношения к Т-Банку, Сберу или GigaChat**.  
> Это личная инициатива разработчика для изучения корпоративного стиля, UX больших технологических компаний и тестирования возможностей GigaChat API.


## О проекте

**T-GPT** — это учебный чат-интерфейс, вдохновлённый стилем цифровых продуктов крупных технологических компаний (включая Т-Банк). Проект создан исключительно в образовательных целях:

- Изучение архитектуры фронтенд-бэкенд взаимодействия
- Практика работы с прокси-серверами и авторизацией в GigaChat API
- Анализ UX/UI корпоративных сервисов
- Тестирование возможностей Giga Code и современных React-паттернов

Проект **не несёт вреда и ущерба компаниям** и не претендует на коммерческое использование.

## Функционал

- Чат-интерфейс с отправкой сообщений
- Прокси-сервер на Node.js для безопасного доступа к GigaChat API
- Кэширование токена авторизации
- Адаптивная верстка (мобильные и десктоп)
- Минималистичный, современный дизайн в стиле корпаративной культуры Т-Банка

## Установка и запуск

### 1. Клонируй репозиторий
```bash
git clone https://github.com/your-username/t-gpt.git
cd t-gpt
```

### 2. Настрой переменные окружения
Сервер:
Создай файл server/.env:
```bash
ENV
PORT=3001
GIGACHAT_AUTH_KEY=ваш_base64_ключ_автори
```

Получить ключ можно на developers.sber.ru

### 3. Установи зависимости и запусти
## Запуск сервера:
```Bash
cd server
npm install
npm run dev
```
## Запуск клиента:
```Bash
cd client
npm install
npm run dev
```

## После запуска:

### Фронтенд: http://localhost:3000
### Бэкенд: http://localhost:3001
